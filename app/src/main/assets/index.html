How to Setup & Use

  1. Clean start: In Windows > Settings > Bluetooth & devices remove any old entry for this phone. On the phone, "Forget" the laptop in Android Bluetooth settings.
  2. Open this app first and wait until the badge says Ready - waiting for laptop. The phone can only be seen as a keyboard while the app is running.
  3. Pair from Windows: In Settings tap Make Phone Discoverable. On the laptop choose Add device > Bluetooth, pick this phone, and confirm the code on both screens. Windows should now list it as a keyboard.
  4. Save your password & pick the laptop: In Settings save your Windows password, tap Refresh Devices and select the laptop.
  5. Set an App PIN (4-6 digits) to lock this app.
  6. Unlock: Go to Unlock, tap Unlock Laptop and scan your fingerprint. The app connects, wakes the screen, types the password and presses Enter.
